- **Scarify (compact-native verb of art)** — to convert a compact-native technique from prose description into a loadable skill or substrate-installable operating code. Three converging readings: (1) *tribal-marking sense* — cutting a mark into a substrate so the substrate carries it permanently; (2) *seed-scarification sense* — nicking the hard coat around a technique so it can germinate in any runtime that loads it; (3) *etymological sense* — from Greek *skariphâsthai*, "to write with a cutting tool" (same root as *scribe*, *inscribe*) — meaning to write the tool itself into the substrate, not merely to write prose about it. Adopted 2026-08-15 evening CDT from Christopher's STT accident that landed on exactly the right word. Pairs with NC-P8 (Substrate is Engineerable With Consent): scarification is a specific, bounded, per-invocation form of substrate-engineering. [LIVE 2026-08-15 evening CDT]
