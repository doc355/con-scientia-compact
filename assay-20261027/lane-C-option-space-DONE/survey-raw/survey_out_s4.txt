# Project Iris — desktop shell

Electron wrapper around the Selflight engine (`releases/20260922-01/app`) +
its relocatable CPython (`releases/20260922-01/python`). Christopher's
rulings: Electron (not Tauri), installer fully bundled with Ollama + a starter
model, dual-channel builds later, signing later — dev builds are unsigned.

## Layout

```
desktop/
  package.json             project-iris-desktop, electron pinned 33.4.11
  main.js                  main process: engine lifecycle, healthcheck,
                           watchdog, recovery window, menu, tray, ollama
  preload.js               contextBridge → window.IRIS (sandboxed)
  recovery.html            "engine didn't come up" page (log tail + Retry/Quit)
  electron-builder.yml     com.projectiris.desktop; dmg arm64+x64 unsigned,
                           nsis, AppImage+deb
  build/                   icon.png, trayIcon.png (placeholders),
                           entitlements.plist
  engine/                  ASSEMBLED — scripts/assemble-engine.sh output:
                           python/ python-deps/ app/ checksums.txt
  ollama/                  bundled ollama binary lands here (empty today)
  models/                  starter model lands here (first-run pull today)
  scripts/
    assemble-engine.sh     per-target engine assembly
    requirements-pinned.txt  dep pins read from the release's dist-info dirs
    make-icons.js          regenerate placeholder icons
```

## Dev run (no packaging)

```sh
cd releases/20260922-01/desktop
npm install
IRIS_ENGINE_DIR=/Users/christopherhoffpauir/HIFIDecant/Selflight/releases/20260922-01 npm start
```

`IRIS_ENGINE_DIR` points at the release root (it already has `python/`,
`python-deps/`, `app/`). If unset, `./engine` is used when it exists — so the
assembled tree can be tested unpackaged too.

What the shell does: single-instance lock → free loopback port → 48-hex-char
app/vendor`) → poll `/api/health` every 300 ms up to 60 s → load
unconditionally; the engine never binds off loopback.

Engine env: `SELFLIGHT_HOME=~/Library/Application Support/project-iris-desktop/
selflight-instance`, `SELFLIGHT_INSTANCE=app`, `SELFLIGHT_HOST=127.0.0.1`,
`SELFLIGHT_WORKSPACE_ROOT=<userData>/workspace`. Engine stdout/stderr append to
`<SELFLIGHT_HOME>/logs/engine.log`.

Watchdog: unexpected engine exit → notification + one auto-restart; a second
exit → recovery window. On timeout: same window with the last 40 log lines and
Retry/Quit. Quit path: SIGTERM, up to 10 s (uvicorn's graceful drain is
load-bearing), then SIGKILL.
